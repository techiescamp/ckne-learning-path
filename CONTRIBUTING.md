# Contributing to the CKNE Learning Path

Contributions are welcome. To keep the content accurate and easy to review, please follow the guidelines below.

## How to Contribute

- **Bug reports / corrections** 👉 Open an issue that describes the error and gives the correct information, along with a source link so it can be checked.
- **Content additions** 👉 Open a pull request. Please keep new content within the CKNE curriculum domains.
- **Typo / formatting fixes** 👉 You can send a pull request directly, because these do not need an issue first.

## Pull Request Guidelines

1. Fork the repo, then create your branch from `main`.
2. Limit each PR to one topic or one fix, so it is easy to review.
3. Before you submit, test your commands and manifests on a real cluster. In the PR, note the Cilium, Istio or Envoy Gateway version you tested with, because behavior can change between versions.
4. Put each topic in the study note for its domain. Link to the official project documentation only once per topic.
5. Do not add content that falls outside the CKNE exam domains.

## Reporting Issues

If you find a problem, open an issue on GitHub: [github.com/techiescamp/ckne-learning-path/issues](https://github.com/techiescamp/ckne-learning-path/issues)

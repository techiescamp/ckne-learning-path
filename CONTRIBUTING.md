# Contributing to the CKNE Learning Path

Contributions are welcome. Please follow these guidelines.

## How to Contribute

- **Bug reports / corrections** 👉 Open an issue describing the error and the correct information with a source link.
- **Content additions** 👉 Open a pull request. Keep additions within the CKNE curriculum domains.
- **Typo / formatting fixes** 👉 Pull requests welcome, no issue needed.

## Pull Request Guidelines

1. Fork the repo and create a branch from `main`.
2. Keep each PR scoped to one topic or fix.
3. Test commands and manifests on a real cluster before submitting. Note the Cilium, Istio or Envoy Gateway version you tested with.
4. Put each topic in the study note for its domain, and link to official project documentation once per topic.
5. Do not add content that is out of scope for the CKNE exam domains.

## Reporting Issues

Open an issue on GitHub: [github.com/techiescamp/ckne-learning-path/issues](https://github.com/techiescamp/ckne-learning-path/issues)
